Yuvraj Yadav – Personal Portfolio

A personal portfolio website showcasing my profile, technical skills, education, and web development projects.

About the Project

This portfolio is designed to introduce me as a BCA student and aspiring Web Developer. It provides a simple way to explore my work, learn about my technical background, and connect with me.

Features

- Clean and minimal user interface
- Responsive layout for desktop and mobile devices
- Indigo and purple accent colour theme
- Dark and light mode toggle
- Dedicated sections for About, Projects, Skills, Education, and Contact
- Profile photo and downloadable resume
- Direct links to GitHub, LinkedIn, and Instagram

Technologies Used

- HTML5 – Website structure
- CSS3 – Styling, layout, and responsive design
- JavaScript – Theme switching and interactive functionality
